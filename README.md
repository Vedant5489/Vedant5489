## What I Work On

- **Full-stack application development** — connecting polished interfaces to maintainable backend services.
- **REST API design** — structuring routes, controllers, services, validation, and middleware.
- **Mobile development** — building Android-focused experiences with React Native and Expo.
- **Offline-first architecture** — local persistence, queued changes, and synchronization between device and server.
- **Payments and subscriptions** — integrating checkout and server-side payment verification.
- **Performance and reliability** — investigating UI bottlenecks, improving data flows, and handling real-world edge cases.

---

## Engineering Principles

- Build for real user workflows, not just demos.
- Keep business logic on the server and validate important operations there.
- Treat network failures as a product-design concern.
- Prefer clear architecture and maintainable code over unnecessary complexity.
- Test critical paths, especially synchronization, billing, and payment verification.
- Ship incrementally and improve from real usage and feedback.
